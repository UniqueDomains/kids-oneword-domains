## 🧱 Field summary

- `domain`, Fully qualified domain name.
- `status`, Current acquisition state for the domain in the public extract.
- `purchase_price`, Visible purchase price when available.
- `renewal_price`, Visible renewal price when available.
- `attractiveness`, Public composite naming band used as a decision-support signal.
- `demand`, Public buyer-pressure band when available.
- `length`, Character count without the TLD.
- `registrar`, Registrar name when known.
- `created_at`, Creation timestamp when known.
- `expires_at`, Expiry timestamp when known.

See [DATA_DICTIONARY.md](./DATA_DICTIONARY.md) for full definitions and types.

## ⚠️ Methodology and caveats

The .kids extension pairs a clear audience signal with short, ownable names such as geton.kids, matcha.kids, and rolemodel.kids. This set spans functional terms, playful brand-style words, and character-adjacent names, giving a wide field to compare pricing against memorability. With a median ask near $70 across thousands of listings, .kids remains one of the more approachable niche extensions for securing a one-word name early.

- Median ask near $70 across 12,457 one-word .kids domains
- 506 TLD variants tracked alongside .kids for comparison
- Mix of functional, brandable, and playful one-word names
- Short names like find.kids and buy.kids signal high utility
